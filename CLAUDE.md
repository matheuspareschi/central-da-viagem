## Coding style

Apply Martin Fowler's criteria when writing and refactoring code in this project: favor small, well-named, single-purpose functions; eliminate duplication; extract abstractions only when they earn their keep; prefer clear names over explanatory comments; and treat code smells (long functions, feature envy, primitive obsession, etc.) as things to address as you touch the code, not just when explicitly asked.
